# 验证计划模板

| 项目 | 填写内容 |
|---|---|
| 功能/版本 | 待验模块、软件和硬件版本 |
| 输入 | 来源、尺寸、单位、存储顺序、SHA256 |
| 参考 | 独立实现与误差标准 |
| 正例 | 合法输入与期望行为 |
| 反例 | 错误形状、错误哈希、时序失败、非有限数 |
| 输出 | 图像、数组、残差、迭代数、运行后端 |
| 性能 | 同条件前后时延、资源、频率；明确计时范围 |
| 证据 | 文件路径与结果；未执行不得填写通过 |
| 失效边界 | 输入不匹配、缺失硬件或依赖时的处理 |

性能表应保留输入、精度、停止规则和资源条件。频率与调度同时改变时只能称组合方案比较，不能把差异全部归因于某一项。
