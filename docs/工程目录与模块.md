# 工程目录与模块

`MODULES.json` 是七个模块到实际源码的映射。`project/repo` 保留源代码相对导入与 include 布局；`project/releases/performance` 保留完整求解器、硬件重建脚本、导出 IP 和冻结文件。

数据流：相机 → RAW 接收与预处理 → 匹配几何/辐射配置 → 测量输入 → FP64 求解与 PS/PL 矩阵运算 → 结果显示/保存。实时预览、论文数据 CPU 演示和板端 PL 求解分别使用对应入口。

- 相机：`project/repo/board/raw_capture`、`project/repo/src/software/camera_service`。
- 动态与范围：`project/repo/src/software/full_model/fast_path`、`dual_mode` 及 `project/repo/src/software/meas_norm/camera_motion`。
- 完整算法：`project/repo/src/software/full_model`、`project/releases/performance/src`。
- 硬件：`project/releases/performance/scripts`、`hardware_evidence/exported_ip`、`hardware_evidence/generated_ps`。
- 控制显示：`project/repo/board/dual_display`、`05_控制与显示程序/paper_live_demo`。
- 97 例：`project/data/batch_manifest.json`、`descriptors`、`assets`。

原冻结 release_manifest 是来源版本的索引；本工程文件的完整性以根目录 MANIFEST.json 为准。不能用历史 release_manifest 的条目数量判断本工程分发范围。
