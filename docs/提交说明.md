# 本地工程交付说明

已参照现有七模块表及提交页“上传项目工程的 GitHub 链接 / GitHub 或 Gitee 开源链接”整理。代码附件页的 RAR、200M 限制针对单独附件，不用于删减本工程的 97 例复现资源。

本目录未创建远程仓库、未上传、未生成链接，也未生成压缩包。自行导入仓库时，须先安装 Git LFS 并执行 git lfs install，再添加文件，使 .gitattributes 对 PFM/bit/XSA/DLL/EXE 生效。网页直接逐个上传不会执行本地 LFS 过滤。

完整下载后执行 `python tools/verify_package.py`。若拿到的是 Git LFS 指针，先取得 LFS 实体文件再检查。MANIFEST.json 是文件字节校验清单，不是运行通过报告。修改源码或文档后需同步更新清单。

本次只做文件整理、依赖/数据引用检查、Python 语法检查及哈希校验；不启动相机、开发板、重建或 Vivado 工具。
